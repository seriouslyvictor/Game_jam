# Brick Borough

A quick Three.js concept for a cozy LEGO-inspired city builder. It uses procedural brick models, instanced base-plate studs, capped device pixel ratio, and on-demand-friendly geometry/material reuse for a lightweight interactive prototype.

## Run locally

```bash
npm install
npm run dev
```

Click the city to place the selected structure, drag to pan, right-drag to orbit, scroll to zoom, and press **R** to rotate the next placement.
